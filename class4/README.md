# 領袖社 第四堂社課 課前QA

- 問卷網址：`https://mikecheng0402.github.io/115_fall_QA/class4/`
- 前端：`index.html`（版面沿用 class2、class3 的米色禪風）
- 後台：`apps-script/Code.gs`，和第二堂、第三堂共用同一份 Google 試算表與同一個 Apps Script 網址

## 題目

開頭：姓名、你的身分（下拉選單：社員、幹部、家族長）、家別（1家到7家），結尾：想問講師的問題（選填簡答）。中間四題都是單選：

| 標籤 | 題目 | 選項 |
|---|---|---|
| 觀察自己 | 你平常會不會主動觀察自己？ | A 我習慣順著當下直覺或別人的安排<br>B 人生的大轉折時，就會去主動檢視<br>C 我每天會刻意留時間，讓自己沉澱內心<br>D 不論在什麼時刻，我會試著關照自己的身心 |
| 壓力反應 | 當你感到壓力時，你的第一反應通常是： | A 我會很想滑手機、做其他事來轉移注意力<br>B 我會想試著解決壓力源，但有時會感到內耗<br>C 我會優先把事情完成，先不去管自己的壓力<br>D 我會停下來試著解開壓力源並讓自己放鬆 |
| 壓力調整 | 當你已經覺得壓力很大，你通常會怎麼調整？ | A 去吃好吃的、玩好玩的，讓自己感到快樂<br>B 會感到焦慮，不敢停下手邊的事，所以也不知如何調整<br>C 通常是被別人提醒自己狀態不好，才開始想辦法休息<br>D 去做喜歡的事情放鬆之後，會再讓自己靜下來體察壓力源 |
| 禪定題 | 禪定時，當你專注力被拉走，你的第一反應通常是： | A 好像比較少留意到這件事，還不確定自己的反應是什麼<br>B 會不由自主的跟著妄念、腳痛，過一段時間才拉回專注<br>C 雖然意識到分心，但需要一小段時間拉回專注<br>D 會當下意識到分心，想辦法更專注<br>E 當下意識到分心後，會試著讓自己身心更放鬆 |

## 後台設定（每新增一堂課做一次）

1. 打開原本的回覆試算表，點「擴充功能 → Apps Script」。
2. 把 `apps-script/Code.gs` 的內容整份貼上，取代舊程式，按儲存。
3. 「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，按「部署」。網址不變，所以 `index.html` 不用改。

這份 `Code.gs` 同時支援第二、三、四堂，貼上後前幾堂的問卷也照常可以送出。

## 表格欄位

回覆存在試算表的「第四堂課前QA」工作表，第一次收到回覆時自動建立。只存每題選了哪個選項，不計分。

| 時間戳記 | 姓名 | 身分 | 家別 | Q1 平常會不會主動觀察自己 | Q2 感到壓力時的第一反應 | Q3 壓力很大時怎麼調整 | Q4 禪定時專注力被拉走的第一反應 | 想問講師的問題 |
|---|---|---|---|---|---|---|---|---|

每題存成「字母 + 選項句子」，例如「C 我每天會刻意留時間，讓自己沉澱內心」。

## 之後要改題目

- 題目文字與選項：改 `index.html` 裡的 `QUESTIONS`。
- 題數或欄位有變時，也要改 `Code.gs` 裡 `FORMS.class4` 的 `headers` 與 `build`，再到 Apps Script 部署新版本。
