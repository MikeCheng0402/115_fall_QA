# 領袖社 第三堂社課 課前QA

- 問卷網址：`https://mikecheng0402.github.io/115_fall_QA/class3/`
- 前端：`index.html`（版面沿用 class2 的米色禪風）
- 後台：`apps-script/Code.gs`，和第二堂共用同一份 Google 試算表與同一個 Apps Script 網址

## 題目

開頭：姓名、家別（1家到7家），結尾：想問講師的問題（選填簡答）。中間五題：

| 題目 | 形式 | 選項 |
|---|---|---|
| 不求回報：你曾經「不求回報」地幫助過別人嗎？事後的感受是？ | 單選 | A 能量滿滿、B 一半一半、C 禮尚往來、D 務實至上 |
| 典範人物：是否曾有一位啟發你內心、讓你由衷想學習的「精神導師」或「典範人物」呢？ | 單選 | A 深受啟發、B 滿心期待、C 理性存疑、D 獨立探索 |
| 領袖特質：你覺得在你心目中，一個領袖最重要的特質是什麼？ | 單選 | A 深謀遠慮、B 寬廣胸襟、C 頂尖專業、D 個人魅力 |
| 世界和平：你對世界和平的看法是什麼？ | 單選 | A 盡己所能、B 心嚮往之、C 理想口號、D 尚未深思 |
| 禪定題：上週社課帶專注大腦，實作的時候感覺有遇到哪些困難呢？ | 複選 | A 難以入門、B 呼吸困惑、C 思緒紛飛、D 後繼乏力、E 腿部不適、F 漸入佳境 |

複選題的「F 漸入佳境」（沒什麼問題）和其他選項互斥：選它會清掉其他選項，選其他選項會取消它。

## 後台設定（只要做一次）

1. 打開原本的回覆試算表，點「擴充功能 → Apps Script」。
2. 把 `apps-script/Code.gs` 的內容整份貼上，取代舊程式，按儲存。
3. 「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，按「部署」。網址不變，所以 `index.html` 不用改。

這份 `Code.gs` 同時支援第二堂和第三堂，貼上後第二堂的問卷也照常可以送出。

## 表格欄位

回覆存在試算表的「第三堂課前QA」工作表，第一次收到回覆時自動建立。只存每題選了哪個選項，不計分。

| 時間戳記 | 姓名 | 家別 | Q1 不求回報的付出 | Q2 精神導師或典範人物 | Q3 領袖最重要的特質 | Q4 對世界和平的看法 | Q5 專注大腦實作的困難（複選） | 想問講師的問題 |
|---|---|---|---|---|---|---|---|---|

- 單選題存成「A 能量滿滿」這種格式。
- 複選題用「、」隔開，例如「B 呼吸困惑、C 思緒紛飛」。

## 之後要改題目

- 題目文字與選項：改 `index.html` 裡的 `QUESTIONS`。
- 題數或欄位有變時，也要改 `Code.gs` 裡 `FORMS.class3` 的 `headers` 與 `build`，再到 Apps Script 部署新版本。
