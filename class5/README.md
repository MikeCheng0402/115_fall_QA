# 領袖社 第五堂社課 課前QA

- 主題：幸福的必要條件（因果、感恩與懺悔）
- 問卷網址：`https://mikecheng0402.github.io/115_fall_QA/class5/`
- 前端：`index.html`（版面沿用 class2 到 class4 的米色禪風）
- 後台：`apps-script/Code.gs`，和第二堂到第四堂共用同一份 Google 試算表與同一個 Apps Script 網址

## 題目

開頭：姓名、你的身分（下拉選單：社員、幹部、家族長）、家別（1家到7家），結尾：想問講師的問題（選填簡答）。中間三題都是單選，選項由 A 到 D 一層比一層深入：

| 標籤 | 題目 | 選項 |
|---|---|---|
| 心念與結果 | 當一件事的結果不如你的預期，你通常會怎麼想？ | A 覺得是運氣不好，或是環境、別人造成的<br>B 會檢討自己哪裡沒做好，但常常停在自責<br>C 會回頭想想，自己當時做了什麼決定、說了什麼話<br>D 會再往前想，是當時的什麼心念，讓我做了那樣的選擇 |
| 感恩日常 | 最近一週，你有沒有對身邊的人表達感謝？ | A 好像沒有特別想到要感謝誰<br>B 心裡有感謝，但不太好意思說出口<br>C 別人幫我忙的時候，我會說聲謝謝<br>D 就連覺得理所當然的小事（家人準備的飯、同學順手幫的忙），我也會留意到，並表達感謝 |
| 面對過錯 | 當你發現自己說錯話或做錯事，影響到別人時，你通常會怎麼做？ | A 不太會多想，時間久了就過去了<br>B 心裡會一直放不下、反覆去想，但不知道怎麼處理<br>C 會找機會道歉，把事情說開<br>D 除了道歉，也會反思自己當時的心念，提醒自己下次怎麼做 |

## 給講師：怎麼讀結果

- **心念與結果**（對應大綱 1、2）：A、B 多的話，「心念才是因」可以多鋪陳；選 B 的人到懺悔那段可以順帶說明懺悔不等於自責。
- **感恩日常**（對應 take away 1）：A 多就用感恩父母影片帶大家先「看見」；B 多就強調感恩便條「寫下來」本身就是表達。
- **面對過錯**（對應大綱 3、take away 2）：B 多就把懺悔講成放下、回到清淨；D 多可以直接進入「懺悔讓下一個念頭變善」。

## 後台設定（每新增一堂課做一次）

1. 打開原本的回覆試算表，點「擴充功能 → Apps Script」。
2. 把 `apps-script/Code.gs` 的內容整份貼上，取代舊程式，按儲存。
3. 「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，按「部署」。網址不變，所以 `index.html` 不用改。

這份 `Code.gs` 同時支援第二到第五堂，貼上後前幾堂的問卷也照常可以送出。**沒有做這一步之前，第五堂的問卷送出會失敗。**

## 表格欄位

回覆存在試算表的「第五堂課前QA」工作表，第一次收到回覆時自動建立。只存每題選了哪個選項，不計分。

| 時間戳記 | 姓名 | 身分 | 家別 | Q1 結果不如預期時怎麼想 | Q2 最近一週有沒有表達感謝 | Q3 說錯話做錯事影響別人時怎麼做 | 想問講師的問題 |
|---|---|---|---|---|---|---|---|

每題存成「字母 + 選項句子」，例如「C 別人幫我忙的時候，我會說聲謝謝」。

## 之後要改題目

- 題目文字與選項：改 `index.html` 裡的 `QUESTIONS`。
- 題數或欄位有變時，也要改 `Code.gs` 裡 `FORMS.class5` 的 `headers` 與 `build`，再到 Apps Script 部署新版本。
